#+begin_src sage

The problem describes the envelope, i.e., the curve which describes
the "cover" of all possible positions of a ladder of fixed length next
to a wall.

Given $a$, the distance of the ladder from the wall, and $b$, the
height of the wall where the ladder touches it, the $(x, y)$ points
corresponding to the line representing the ladder are given by:
#+begin_src sage
  x, y, a, b, L = var("x, y, a, b, L")
  assume(a>0, b>0, x>0, y>0)
  ladder = x / a + y / b == 1
  assume(ladder)
  print(fr"\[{latex(ladder)}\]")
#+end_src

#+RESULTS:
:results:
\[\frac{x}{a} + \frac{y}{b} = 1\]
:end:

Assuming the length of the ladder is $L$ then $a$ and $b$ must
satisfy:
#+begin_src sage
  ladder_len = L^2 == a^2 + b^2
  assume(ladder_len)
  print(fr"\[{latex(ladder_len)}\]")
#+end_src

#+RESULTS:

To use the envelope equations we express $b$ as a function of $a$
#+begin_src sage

#+RESULTS:

$b = \sqrt{L^{2} - a^{2}}$
:end:

I.e., we solve the system of the following system of two equations:

#+begin_src sage
  fxya = ladder.substitute(b == sol_b.rhs()) - ladder.rhs()
  dfxya = fxya.diff(a)
  print(r"\begin{align*}")
  print(rf"f(x,y,a) &\equiv {latex(fxya)} \\")
  print(rf"\frac{{\partial f(x, y, a)}}{{\partial a}} &\equiv {latex(dfxya)}")
  print(r"\end{align*}")
#+end_src

#+RESULTS:
:results:
\begin{align*}
f(x,y,a) &\equiv \frac{y}{\sqrt{L^{2} - a^{2}}} + \frac{x}{a} - 1 = 0 \\
\frac{\partial f(x, y, a)}{\partial a} &\equiv \frac{a y}{{\left(L^{2} - a^{2}\right)}^{\frac{3}{2}}} - \frac{x}{a^{2}} = 0
\end{align*}
:end:


The solutions for $x$ and $y$ are as follows:
#+begin_src sage
  sol_xy = solve([dfxya, fxya], [x,y])[0]
  print(r"\begin{align*}")
  for sol in sol_xy:
    print(rf"{latex(sol.lhs())} &= {latex(sol.rhs())}\\")
  print(r"\end{align*}")
#+end_src

#+RESULTS:
:results:
\begin{align*}
x &= \frac{a^{3}}{L^{2}}\\
y &= \frac{{\left(L^{2} - a^{2}\right)}^{\frac{3}{2}}}{L^{2}}\\
\end{align*}
:end:

By raising both equations to the power of $2/3$ we get
#+begin_src sage
  sol_xy = [(s^(2/3)).canonicalize_radical() for s in sol_xy]
  print(r"\begin{align*}")
  for sol in sol_xy:
    print(rf"{latex(sol.lhs())} &= {latex(sol.rhs())}\\")
  print(r"\end{align*}")
#+end_src

#+RESULTS:
:results:
\begin{align*}
x^{\frac{2}{3}} &= \frac{a^{2}}{L^{\frac{4}{3}}}\\
y^{\frac{2}{3}} &= \frac{L^{2} - a^{2}}{L^{\frac{4}{3}}}\\
\end{align*}
:end:

When combined we get the curve of the envelope, which is an /astroid/.
